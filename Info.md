Данный BackEnd развернут в облаке и принимает запросы только на два URL. 

[1] POST-запрос на URL = https://lainer.containerapps.ru/auth/signUpJWT \
c "body"(raw) в виде вот такого "JSON" \
   {\
   "login" : "test-usr",\
   "password" : "test-pwd",\
   "roles": ["USER", "ADMIN"]\
   }\
Данный запрос возвращает токен. 

[2] POST-запрос на URL = https://lainer.containerapps.ru/auth/signInJWT \
при этом надо задать "Auth Type" = "Bearer Token" и указать токен из первого запроса.

P.S.: Данный backEnd развернут как «холодный» экземпляр контейнера, это означает, что::\
[1] контейнер с backEnd-ом не находиться в постоянно «развернутом» состоянии; \
[2] контейнер с backEnd-ом начинает «разворачиваться» только при получении первого запроса; \
[3] время «развертывания» контейнера после получения первого запроса обычно составляет 30-90 секунд; \
[4] после обработки крайнего запроса, если в течение 15 минут не поступают новые запросы, то \
контейнер с backEnd-ом:: останавливается.
